# Model Artifact and Inference Schema

## Artifact schema version 1

Artifacts are joblib dictionaries. The registry validates the fields below before they become dashboard-selectable.

| Field | Type | Meaning |
|---|---|---|
| `artifact_schema_version` | integer | Version of this artifact contract; current value is `1`. |
| `artifact_role` | string | `deployment_candidate` for trained candidate/deployment artifacts. |
| `deployment_selected` | boolean | Whether the candidate was selected as the task deployment alias. |
| `model` | sklearn pipeline | Fitted pipeline with a `model` step and `predict_proba`. |
| `model_family` | string | `svm`, `rf`, or `xgboost`. |
| `task` | string | `binary` or `multiclass`. |
| `classes` | list[string] | Binary: `Faulty`, `Healthy`; multiclass: `Ball`, `Inner_Race`, `Normal`, `Outer_Race`. |
| `features` | list[string] | Ordered 25-feature vector used by training and inference. |
| `feature_version` | string | Current value: `cwru-signal-features-25-v1`. |
| `window_size` | integer | Current value: `2048`. |
| `target_sampling_rate` | integer | Current value: `12000`. |
| `supported_input_sampling_rates` | list[integer] | Current values: `12000`, `48000`. |
| `resampling_method` | string | FIR decimation by four with zero phase for 48 kHz input. |
| `preprocessing` | object | JSON-serializable copy of the shared preprocessing contract. |
| `hyperparameters` | object | Modal LOLO-selected parameters used for the full-data refit. |
| `selection` | string | Selection rule and candidate/deployment status. |
| `validation` | object | Selection scheme, metric, and candidate LOLO macro-F1 values. |
| `dataset_identity` | object | SHA-256 identities for the manifest and processed 2048-sample feature table. |
| `created_at_utc` | string | UTC artifact creation timestamp. |

## Inference result schema

`src/inference.py::analyze_signal` returns `InferenceResult` from `src/contracts.py`. It includes the selected task/model, classes, source and processed rates, duration, window counts, discarded tail count, recording probabilities, window probabilities and predictions, predicted class, confidence, optional Health Index, first-window waveform/features, and warnings.

## Compatibility rules

An artifact is rejected when its task, class mapping, feature order, feature version, window size, target rate, or supported input rates do not match `src/config.py`. Missing legacy metadata may be read with documented defaults for migration, but newly trained artifacts must be self-describing.

## Registry

`results/model_registry.json` is generated by `src/model_registry.py`. It contains the accepted model entries, the shared contract, and rejected artifact diagnostics. The dashboard must use this registry rather than scanning arbitrary joblib files.
